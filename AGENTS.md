# Repository instructions

## Branch naming

- Follow this repository's existing branch naming convention. Do not use the default `codex/` prefix.
- Use `feat/<description>` for features, `fix/<description>` for fixes, and `chore/<description>` for maintenance, consistent with existing branches.
- Inspect existing branch names before creating a branch and preserve any explicitly requested branch name.
- This is an explicit user preference and must persist across future chats working in this repository.
